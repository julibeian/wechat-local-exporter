# v1.6.0 候选版开发说明

v1.6.0 新增离线 HTML，并把普通聊天的默认导出格式从 JSON 调整为 HTML；PDF 继续作为旧版兼容格式保留。该版本仍处于候选阶段，尚未发布。

## 两批实现范围

第一批完成端到端 HTML 导出：GUI 默认选择 HTML，服务层按会话生成离线归档，导出历史可打开入口文件。归档显示头像、群成员名称、图片、动态表情和文件信息，并提供全文搜索、成员/类型/日期筛选及响应式布局。TXT、JSON 和 JSONL 会把已验证的 `[爱心]` 显示为 `❤️`，JSON/JSONL 另存 `raw_text` 以保留原始值。

第二批负责大数据量验证、性能收口、成品打包验证和文档。PDF 暂不删除，作为旧版兼容格式保留；后续是否继续维护以真实用户使用情况为依据。

## 离线与隐私边界

- 导出的 HTML、CSS、JavaScript、分块消息和媒体均保存在同一归档目录并使用相对路径。归档页面不引用外部资源，断网后仍可查看。
- 导出只读取当前电脑已经保存的微信数据库和媒体缓存，不会从手机或微信云端补齐完整历史。
- 默认不联网补全缺失媒体。用户明确开启联网补全时，只允许现有解析器认可的微信官方媒体地址；聊天内容不上传。
- 缺失、超限或无法识别的媒体会在归档中标明状态，不会伪造内容，也不会把未知表情占位猜成某个 Unicode 表情。
- JSON/JSONL 面向程序和 AI。显示文本与 `raw_text` 分开保存，程序可选择可读文本或原始文本。

## 兼容性

可见产品名保持“微信聊天本地导出工具”。仓库名、`WeChat-TXT-PDF-Exporter.exe`、安装目录和安装器 AppId 不变，避免破坏现有快捷方式、覆盖安装与更新流程。
