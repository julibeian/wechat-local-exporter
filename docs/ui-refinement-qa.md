# 导出界面与富消息修订验收（2026-09-09）

此记录对应用户随后提供的 18 张截图意见；早先重做记录见 `html-redesign-qa.md`。

## 已实现

- 桌面导出基础功能由请求层默认开启，去掉四个基础勾选项、附件实体勾选项、TXT 后缀及多余说明；本机视频和联网补全保留为可选项。聊天记录默认不复制附件实体，批量聊天文件仍为独立任务。
- 导出历史与打开文件、打开文件夹移至底部操作区。完成后原位显示绿色圆形对号，不自动弹完成框或打开浏览器。导出区测量预留确认文本高度，按钮完整显示。
- 修复安装版高 DPI 启动时字体缩放而窗口尺寸未缩放的问题；初始尺寸与最小尺寸随 DPI 调整，避免联系人列表只剩表头。
- HTML 成员菜单包含头像和昵称；类型菜单按截图排列。菜单支持键盘及边界翻转，筛选作用于消息正文。页脚显示项目链接和实际版本。
- 文件以独立卡片展示名称、大小及类型图标；转账展示消息中真实存在的金额和状态；引用分离回复正文与下方灰色引用，并解析昵称。撤回消息优先读取可见替换文案。
- 修复分块注册后立即再次加载同一分块时，旧脚本 load 事件误删新请求的竞态；保留原生滚动和最多 160 条消息 DOM。

## 验证

- `scripts/build.ps1`：278 项测试通过，打包自检、更新测试及本机安装完成。桌面快捷方式指向更新后的安装目录。
- 原生 Tk 布局测试在实际显示窗口后验证底部按钮边界、请求默认值与完成动作；没有通过手工重置 sash 掩盖冷启动布局问题。
- 新增独立进程冷启动测试，执行与安装版相同的 Windows DPI 初始化，验证至少五行联系人及完整导出按钮。解锁后实际检查了修复前后窗口，确认列表高度与底部操作区恢复正常。合成数据桌面截图保存于 `outputs/viewer-qa/native-refinement-final.png`。
- Browser 使用合成数据检查成员和类型筛选、空结果、重置、引用、文件、转账、浅色与深色主题，以及窄屏菜单。50,000 条消息、25 个分块的首尾及相邻块导航正常，DOM 保持 160 条，未发现控制台错误。
- 实际本机记录同时导出 TXT 和 HTML，并开启联网补全：群聊 8,457 条，379 处引用，1,082 个可用媒体、0 个缺失媒体；私聊 519 条，3 处引用，39 条转账，76 个可用媒体、5 个缺失媒体。所有生成文件校验清单通过。
- 群聊 62 个成员中有 54 份可用真实头像；私聊双方均有真实头像。缺失资源仍使用明确的回退显示，不伪造原始资源。
