# HTML 阅读界面与原生表情修复

## 用户可见的变化

- 日期筛选使用与成员、类型筛选相同的箭头和布局；三个箭头垂直居中，右侧间距一致。页脚的项目名、版本号与操作按钮重新对齐。
- 全部成员菜单支持搜索姓名，包含群成员昵称、联系人备注与昵称；支持空结果提示和键盘选择。

- 导出预估文字删除多余空格，使用 ASCII `-` 分隔；例如 `约1秒-1秒-21条-图片3-表情0-预计大小约1.7MB`。
