# 导出大小、列表表情与表情缓存修复验收

2026-10-10 的本机 v1.6.1 修复。保留之前的图片、视频、微信绿色气泡和 GitHub 官方图标；尚未上传或发布。

## 大小预估

原来的 3.3–401.9 MB 区间混用了媒体缓存大小和转换后图片的假设上限，不能指导实际导出。现在显示一个近似值：TXT、JSON 和纯文字 PDF 按真实序列化计数；HTML 和 AI 资料包按本机图片、表情实际解码后的长度统计，使用正式导出的资源去重与元数据结构。带图片 PDF 计入图像压缩和遮罩，附件 ZIP 使用真实压缩或至多 96 KB 的样本。联网媒体大小未知时单独显示待定数量。

首次计算 HTML 或媒体资料包时，后台解码本账号本机资源，丢弃图片内容，仅缓存源文件签名、字节数、格式与摘要。源文件变化后重新计算。预估不下载媒体、不获取微信进程密钥、不生成导出文件；纯文字和聊天文件预估不解码图片。账号密钥在连接时验证并使用 Windows DPAPI 保存。

四种任务均独立显示宋体提示，选中对象、日期、格式、图片与视频选项、联网开关、文件类型和大小上限变化后更新。后台任务可取消，旧结果不会覆盖新选择。重新连接及导出结束后清空界面统计缓存，防止新资源或新密钥恢复后仍显示旧值。

## 表情显示与表情包

列表原先只替换为 Unicode，Windows Treeview 会把部分表情画成单色小字。现在使用系统 Segoe UI Emoji 的彩色字形生成位图，覆盖含表情的最近消息单元格；原文字仍用于搜索。表情随行文字高度缩放、垂直居中，滚动、窗口大小变化、选择和 Ctrl 多选均保持有效。未知标签和媒体占位保留。

导出表情包的另一处原因是本机新版缓存使用独立加密格式。密钥为 `MD5(str(UIN) + wxid + "EMOTICON")` 的 16 字节原始摘要；缓存为 AES-128-CBC，IV 为该密钥，使用 PKCS7。UIN 按完整 64 位读取，必须匹配当前账号，并对缓存文件解密验证后才能保存密钥。遍历 Persist、PersistStore、每月 Emoticon、Thumb 和 ThumbStore；兼容 androidmd5 标识及缩略图兜底。

CDN 的消息密钥与账号缓存密钥不同。32 位十六进制消息密钥解码后，先尝试 CBC（IV 为密钥），再兼容旧 ECB；验证媒体签名，避免错误模式被误认成图片。本机 WXGF 解密后使用正式导出的 FFmpeg 解码流程。

真实反馈会话有 66 条表情具备本机缓存，已全部成功导出，GIF 动画字节保持原样；其余 160 条没有本机缓存，离线导出保留缺失说明。联网补全是用户可选项，不能把未缓存资源计作已恢复。该会话还有 60 条图片缺少本机资源，未以缩略图或表情结果掩盖。

HTML、带图片 PDF、AI 资料包均验证了加密表情恢复；HTML 和 AI 保留 GIF 动画，PDF 使用静态画面。TXT/JSON 属于文字导出，保留表情占位与内置字符，不承诺携带图片。此前“家”群修复已验证 HTML 77 项媒体、PDF 66 张图片、AI 资料包 66 张图片及 11 段视频。
