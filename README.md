# 微信聊天 TXT / PDF 导出工具

- 1.私人电脑里的微信聊天记录（联系人&群聊）通过TXT和PDF格式导出
- 2.对单个联系人的本机可见朋友圈以“离线HTML+JSON+原始媒体归档”形式导出。
- (ps.信息在本机独立导出+存储，不上传聊天内容)

 [使用说明](#使用) 
**本工具仅读取这台电脑本地已经保存的微信数据库，不会从手机或云端补齐完整历史记录。因此建议在该微信账号长期使用的 Windows 电脑上运行。**

在陌生电脑临时扫码登录，只能读取实际同步到该电脑的数据，不等于完成聊天迁移。
登录、设备认证和扫码始终由微信客户端负责，本工具不保存微信 Cookie、Token 或其他登录凭据。

## 数据来源与联网范围

- 聊天和朋友圈记录读取本机微信数据库，只导出本机已有内容，不会从云端拉取全部历史。
- 朋友圈图片、视频根据本机记录中的媒体链接尝试从微信服务器下载，也会读取本机缓存；媒体是否完整取决于文件是否仍可取得。
- 聊天数据库仅在本机处理 · 密钥只保存在内存 · 不上传聊天数据 · 不修改微信。检查更新及部分媒体获取功能可能联网。
- 更新检查只读取公共 GitHub Release，无需 GitHub 登录，不携带微信账号、路径或聊天内容。无法访问 GitHub 时只显示“暂时无法检查更新”，不会影响本地连接和导出。
- “本地导出、不上传”指内容在本机处理和保存，不代表完全不联网。换电脑后，需要先让微信把所需记录同步或迁移到该电脑。

## 功能

- 优先从运行中的微信进程识别账号；无法唯一确认时明确提示，不用目录修改时间猜测登录账号。
- 优先无重启连接；只有底层要求重新启动时，才询问是否继续。微信重新登录后重新识别账号，支持从 A 切换到 B。
- 点击标题旁版本号查看版本历史、更新状态并下载更新；安装包和便携版均通过独立更新进程完成交接。
- 在“类型 ▾”表头中折叠筛选全部类型、联系人或群聊；联系人和群聊按姓名拼音/字母分组排列，可按日期范围导出。
- TXT 和 PDF 默认导出微信已有的语音转文字，并提供图文“详细”引导。
- 回复消息会附带被引用的原文；合并转发的聊天记录会展开其中的发送者、时间和逐条内容。
- 默认使用快速模式；需要原图和表情时可手动选择完整模式。
- 联系人、群聊和每个会话分别保存，不会混在同一文件夹。
- 联系人列表顶部提供“我自己”条目；可导出自己的全部本机朋友圈，也可选中单个联系人导出当前账号可见的朋友圈。
- 自己的归档不按公开状态过滤，包含本机库中的仅自己可见、部分可见和不给谁看等私密动态，并逐条标注可见范围。
- 输出自包含的 `index.html` 时间线、`moments.json` 索引、SHA-256 清单及 `media/` 原始媒体目录。
- 照片保存解密后的原始字节，不做额外有损重编码；网页中点击照片可直接打开原文件放大。
- 普通视频和实况照片视频均会归档，并可在离线网页中直接播放。
- 实况照片动态媒体无法取得或浏览器无法播放时，HTML 优先显示该动态自带的静态主图；独立 GIF/WebP 仍保留动画，并准备最后停止帧作为浏览器兜底。
- 保留导出历史，可查看时间并直接打开文件位置。
- 聊天和朋友圈分别显示预计耗时，避免混淆两种导出任务。

## 使用

1. 在常用 Windows 电脑打开并登录微信，再点击本工具的“连接微信并读取会话”。软件启动不会自动关闭微信或弹出连接确认。
2. 优先尝试无重启读取。如果需要重新启动，确认提示后在微信窗口完成登录；账号以此次实际登录为准。
3. 按需在“类型 ▾”中筛选联系人或群聊，再选择会话、日期、格式和输出目录。
4. 导出聊天时点击“导出选中会话”。
5. 导出自己的朋友圈时选择“我自己”；导出他人朋友圈时只选中该联系人，然后点击“导出该人朋友圈归档”。该功能与聊天 TXT/PDF 勾选状态无关。

快速模式优先速度，PDF 中的图片和表情使用可搜索占位文字；完整模式额外读取原图和表情，耗时更长。TXT 内容不受模式影响。

朋友圈归档不受聊天日期范围和快速/完整模式影响。选择“我自己”时读取 `sns.db` 中属于当前账号的全部本机记录，包括仅自己可见和分组可见动态；选择联系人时读取当前账号仍可见的记录。若更早内容或媒体尚未同步到电脑，请先在微信中打开对应朋友圈并向下滚动加载，再重新连接本工具。原文件不可用时会在 HTML、JSON 和完成提示中明确标注缩略图或缺失，不会静默冒充原文件。

语音转文字需先在微信中对语音选择“转文字”，等文字显示后再连接并导出。TXT/PDF 都会默认写入该文字。

导出目录结构：

```text
微信聊天导出/
├─ 联系人/
│  └─ 联系人名称 [标识]/
│     └─ 朋友圈/
│        └─ 联系人名称_朋友圈离线归档/
│           ├─ index.html
│           ├─ moments.json
│           ├─ manifest-sha256.txt
│           └─ media/
├─ 本人/
│  └─ 我自己 [标识]/
│     └─ 朋友圈/
└─ 群聊/
   └─ 群聊名称 [标识]/
```

> 请只处理本人有权访问的数据，并妥善保管导出的聊天记录。

## 兼容范围

- Windows 10/11 x64
- 微信 4.x（v1.2 已针对 4.1.12.55 验证；v1.3 的真实账号切换、重启捕获仍需在目标微信版本人工回归）
- TXT：UTF-8 with BOM
- PDF：A4、中文可搜索文本
- 朋友圈：微信 4.x `sns/sns.db` 本机可见记录；离线 HTML、JSON、原始照片/视频和 SHA-256 清单

- **v0.3–v0.4**：完成本机 TXT/PDF 基础导出和 Windows 独立程序。

- **v1.1**：加入单个联系人**朋友圈 PDF 导出**。
- **v1.2**：朋友圈改为HTML+JSON+原始媒体归档；修复 ISAAC-64 原图解密，并补齐普通视频和实况照片视频。
- **v1.3**：**软件内更新**、账号重新确认、无重启优先连接、安全 codec 缓存、退出清理等待和稳定安装文件名。

## 版本与更新

- 启动 4 秒后后台静默检查；包括失败在内，每 24 小时最多自动尝试一次。手动点击“重新检查”不受此限制。当前已经是最新版本时不弹窗。
- 新版本在主界面显示小横幅；关闭后记录该版本，下次启动不会再主动提醒同一版本，标题旁仍保留新版本状态。以后有其他新版本才重新显示横幅。
- “版本与更新”展示当前/最新版本、GitHub 发布时间和 Release 内容。离线可查看程序内附带的 `RELEASE_NOTES.md`。Release 更新说明来自同一文件，下载表由发布脚本按 tag 自动生成。
- “下载并更新”在软件内下载并验证 SHA256，不强制跳浏览器。完成后由用户确认退出；独立更新程序等待主程序退出，再安装/替换并启动新版。进行连接或导出时不能开始安装。
- 下载、校验、更新进程启动失败时保留当前程序；替换/启动失败会尝试恢复旧 EXE。安装版通过原 Inno Setup 安装目录升级，无须管理员权限。未成功的更新目录中保留 `previous.exe` 供恢复。
- 安装版路径仍为 `%LOCALAPPDATA%\Programs\WeChatChatExporter`，正式 EXE 自 v1.3 起使用 `WeChat-TXT-PDF-Exporter.exe`。安装时移除该目录中旧的 `WeChat-TXT-PDF-Exporter-v*.exe` 并更新标准快捷方式。
- Release 下载表提供带版本号的安装包、便携版和 SHA256 校验文件。便携版原地替换时保留用户当前文件名，界面版本号以程序内部版本为准。
- **v1.2 没有更新入口，因此首次升级到 v1.3 仍需手动运行一次 v1.3 安装包**。之后才可软件内更新。已有导出、历史记录不迁移、不删除；手工创建的旧版快捷方式可能需要重新指向稳定文件名。

更新缓存和非敏感设置保存到 `%LOCALAPPDATA%\WeChatChatExporter\settings.json`，更新下载在同目录的 `updates/`。codec 缓存只有 DLL 路径、大小、修改时间一致才复用，微信升级后重新扫描。账号/路径只是提示，不能替代当前进程确认。配置损坏、目录不可写都不会使离线导出依赖配置成功。

解密副本仅在系统临时目录，正常退出和连接失败会清理；关闭窗口时先等待工作线程完成，避免一边查询一边删除。强制结束进程或断电无法保证清理，不承诺安全擦除磁盘或 Python 内存。请避免在连接、导出过程中强制结束程序。

多微信同时运行或同一进程残留多个账号路径时，v1.3 安全停止账号确认，请只保留目标账号再重试。当前仍完整准备消息库；按需解密的设计、验证结果及未纳入原因见 [v1.3 开发说明](docs/v1.3.0-development.md)。

## 开发

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m wechat_exporter
```

打包：

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean packaging\WeChat-TXT-PDF-Exporter.spec
```

也可运行 `scripts\build.ps1` 完成测试、打包、离线自检、Inno Setup 构建和 SHA256 清单生成。默认只产生 `dist/` 成品，不修改已安装版本；显式传入 `-Install` 才运行安装并更新桌面入口。GitHub tag 发布继续使用 `.github/workflows/release.yml`，不会因本地构建自动发布。
