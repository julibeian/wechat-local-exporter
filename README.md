# 微信聊天本地导出工具

把本机微信聊天和朋友圈导出为可搜索的离线 HTML，也支持 JSON、TXT、PDF 和带媒体的 JSONL 资料包。聊天内容在本机处理。

>后续将依据反馈问题维护更新

当前仅支持 Windows 10/11 x64、微信 4.x，无需安装 Python。

最新版本v1.6只提供一键安装包，安装后会创建桌面快捷方式。

## 功能

| 任务 | 输出 | 用途 |
| --- | --- | --- |
| 聊天记录 | HTML（默认）、JSON、TXT 或 PDF | 离线阅读、搜索、归档或文字分析 |
| AI 完整资料包 | 每个会话一个 ZIP（JSONL + 媒体） | 交给 AI 分析较完整的上下文 |
| 批量聊天文件 | 每个会话一个附件 ZIP | 集中提取 Word、PDF、Excel 等文件 |
| 朋友圈归档 | HTML + JSON + 媒体 | 离线浏览和保存本机可见朋友圈 |

HTML 是日常阅读的推荐格式。它生成一个完全离线的文件夹，可在系统浏览器中查看头像、消息气泡、图片和动态表情，并按文字、成员、类型或日期查找记录。

HTML 查看器可以把**当前分块的全部消息**打印或另存为 PDF。只有一个分块时等同于全量；有多个分块时会明确提示仅包含当前分块，不会把超大归档一次性装入浏览器。需要单个 PDF 包含全部多分块记录时，暂时继续使用旧版 PDF 导出。

JSON 和 TXT 适合快速导出文字。已验证的微信内置表情会直接显示为 Unicode 字符，例如 `[爱心]` 显示为 `❤️`；无法确认的占位文本保持原样。JSON 同时保留 `raw_text`，方便程序追溯原始内容。PDF 的交互和表情还原能力不如 HTML，现阶段只为兼容旧工作流保留。

AI 完整资料包默认收录本机已有的图片、表情和单个不超过 100 MB 的视频；原始语音不装包，只保留微信已有的转写。聊天文件请用独立的批量导出任务。

## 使用

1. 在**常用电脑**打开本工具，微信窗口将在数秒后弹出，届时请手动点击登录。
2. 进入软件页面操作。
3. 选择保存位置，确认导出。

四种任务各自显示预计导出大小，修改日期、格式、视频开关、文件类型或单文件上限后自动更新。这里的大小是导出文件或整个归档文件夹的磁盘占用，不是运行时内存。HTML 和媒体资料包按本机资源实际解码后的字节数估算，并缓存结果；纯文字格式不解码图片。联网资源大小未知时单独提示待定数量，不再用过宽的区间。估算不会下载媒体或提前生成导出文件。最近消息列表和 HTML 中的内置表情使用微信原生图片，大小随文字调整。

同电脑、同账号再次打开时会核对当前登录账号，复用经过校验的本地缓存，并只刷新变化的数据库。微信已登录时也支持快速打开；账号切换或缓存失效时会重新核验、获取密钥并解密。首次加载耗时仍取决于本机记录量。

图片和表情缓存密钥使用 Windows 加密保护并按账号保存，校验通过后无需微信进程运行即可解密本机资源。旧版升级后首次使用时，请在对应微信账号登录期间连接一次；缓存损坏或账号变化时需要重新登录获取密钥。原图无法解码时会尝试本机缩略图，并明确标注。没有本机缓存的表情需勾选“联网补全”才能尝试从微信 CDN 获取；GIF 动画在 HTML 和 AI 资料包中保留，旧版 PDF 使用静态画面。

关闭窗口后程序留在系统托盘，导出继续运行；完成或失败会通知。
